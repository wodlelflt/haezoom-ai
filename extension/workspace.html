드래그 도우미 사용법

  1. 공지 웹페이지에서 해줌 아이콘을 누르세요.
  2. ‘이 사이트 해줌 버튼 켜기’를 누르고 해당 사이트 권한을 허용하세요.
  3. 오른쪽 아래 동그란 h. 버튼을 누르면 기능 메뉴가 열려요. 문장을 드래그하면 옆에도 정리 버튼이 나타나요.
  4. 버튼을 누르면 원래 페이지 안에서 선택 문장을 확인하고 수정할 수 있어요.

키보드 Shift + 방향키 선택도 지원해요. Esc로 닫을 수 있고, 입력창에서 작성 중인 글에는 표시하지 않아요. 사이트별로 끌 수 있어요. 분석 버튼을 누르고 동의하면 원문 텍스트를 Cloudflare Worker를 통해 Claude API로 전송합니다. 캡쳐 이미지는 전송하지 않습니다.

후속 개발 범위

AI 분석 연결은 완료됐습니다. 목록의 영구 저장, 알림과 캘린더 연결은 후속 개발 범위입니다. 수작업 샘플은 실제 AI 결과가 아닙니다. 선택 문장과 캡쳐 이미지는 페이지 안의 확인 창에서 처리합니다. 캡쳐 글자 읽기 작업이 끝나면 백그라운드 처리 화면도 닫습니다.
