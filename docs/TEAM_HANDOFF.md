# 해줌 AI 팀 공유 · PM 박서준

저장소: https://github.com/swjun08/haezoom-ai

저장소 링크와 아래 구현 범위·후속 업무를 팀에 함께 공유하시면 됩니다.

## 이번에 제가 구현한 범위

2.6 변경: 캡쳐와 문장 드래그 모두 원래 페이지 안에서 내용을 확인·수정·복사합니다. 캡쳐 후 iframe을 열던 경로를 제거해 빈 창 문제를 피했습니다. 이미지는 비율을 보존해 전체를 표시하고 크게 볼 수 있습니다. 캡쳐 확인 창은 이미지와 편집창을 좌우로 배치하고 주요 버튼을 고정했습니다. 문서 정리 화면도 데스크톱 한 화면에 입력·결과·주요 버튼을 배치했습니다. PDF 업로드는 별도 문서 정리 화면을 사용합니다.

`review.js`가 캡쳐와 드래그의 공통 확인 UI입니다. `background.js`의 `selection`은 해당 페이지에 `showSelectionReview`를 전달하며 새 탭이나 세션 전달값을 만들지 않습니다. 캡쳐 이미지는 로컬 OCR 단계를 거치지 않고, 원문 확인·동의 뒤 `analyzeImage` → Worker → Claude 이미지 입력으로 전달됩니다. PDF·이미지도 선택 시에는 페이지 수만 확인하고, 분석 동의 뒤 원본 파일을 Worker로 전송합니다. 로컬 파일과 이미지 원본은 영구 저장하지 않습니다. `captureResult`, `pendingCapture`, `pendingSelection` 기반 인계 방식은 폐기했습니다.

페이지 내 확인 창의 ‘할 일 정리하기’와 문서 정리 화면의 `run` 버튼은 공통 `extension/api.mjs`를 통해 Claude 분석 API를 호출합니다. 두 경로 모두 전송 전 동의를 받고, `validateAnalysis`와 `makeItems`를 거쳐 원문 근거·상세 필드를 보여줍니다. 저장·알림·캘린더는 연결하지 않았습니다. Worker와 정적 자산 설정의 기존 버전은 운영 배포되어 있지만, 이번 PDF·이미지 원본 직접 분석 변경은 로컬 구현이며 새 Worker 버전은 dry-run 후 배포 승인 대기입니다. 실제 파일 분석 요청은 보내지 않았습니다.

이번 작업은 기존 Haezoom Worker와 현재 확장 프로그램을 연결하고, 운영 정적 사이트 자산 제공을 보존하는 설정을 복원했습니다. 기존 CRX는 참고 자료로 두고 새 확장 프로그램을 구성했습니다. 영구 저장·알림·Calendar 연결은 후속 범위입니다.

## 현재 상태를 꼭 구분해 주세요

- 샘플 버튼은 수작업으로 작성한 예시 결과입니다. 실제 AI 분석이나 정확도 검증 결과가 아닙니다.
- 목록의 수정·완료·삭제는 현재 화면 메모리에서 동작합니다. 새로고침하면 초기화됩니다. 영구 저장은 미연결입니다.
- 선택 텍스트와 캡쳐 이미지는 페이지 안 확인 창에서 유지합니다. 분석 동의 시 선택 원문은 텍스트로, 캡쳐 이미지는 이미지 자체로 Worker를 거쳐 Claude에 전송합니다. PDF·이미지도 원본 파일로 전송하며 이미지 속 개인정보가 포함될 수 있습니다.
- Cloudflare Secret `ANTHROPIC_API_KEY`, 변수 `CLAUDE_MODEL`, IP당 분당 10회 제한을 사용합니다. 키 값은 확장 프로그램이나 저장소에 넣지 않습니다.
- PDF 페이지 수 확인은 로컬에서 수행하며 파일/캡쳐의 OCR은 Claude가 분석 중 함께 수행합니다. 복잡한 표·스캔 PDF·작은 글씨 등의 정확도는 실제 문서 세트로 추가 검증해야 합니다.
- 전체 사이트 자동 표시는 최초 웹사이트 접근 권한 승인이 필요합니다. 크롬 설정·웹스토어 등 제한 화면까지 지원한다는 의미는 아닙니다.
- 로컬 PDF 로고는 Chrome의 ‘파일 URL에 대한 액세스 허용’이 필요합니다. PDF 내부 텍스트 선택을 직접 읽는 기능은 미구현이며 캡쳐/업로드 경로를 사용합니다.
- 화면 캡쳐 권한이 부족하면 상단 해줌 아이콘의 ‘현재 화면 캡쳐하기’로 시작해야 합니다.

## 팀원이 이어서 해주실 일

### AI 담당

1. 완료: `run`과 `review.js`가 같은 Worker API를 호출합니다. Claude 모델은 Worker의 `CLAUDE_MODEL` 설정으로 제어합니다.
2. 완료: `summary / tasks / schedules` 응답은 `core.mjs`에서 검증·변환되며 준비물·비용·제출처·근거·검토 상태를 유지합니다.
3. 완료: 연도가 없는 날짜를 Worker에서 연도 보정하지 않고 원문으로 유지해 사용자가 확인하도록 합니다.
4. 샘플 문서 5개 이상에 대해 원문·기대값·실제 JSON·누락/오류를 기록해 주세요. 현재 고정 샘플을 AI 성공 사례로 사용하지 말아 주세요.
5. 부분 완료: API 키는 Cloudflare Secret으로 관리하고 IP당 분당 10회 제한·입력 제한·오류 응답·타임아웃·전송 동의를 적용했습니다. 사용자 인증과 추가 악용 방지 정책은 별도 검토가 필요합니다.

## 개발 시작

`chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → 저장소의 `extension` 폴더 선택. 일반 사이트는 해줌 팝업에서 전체 사이트 모드를 한 번 승인합니다. 로컬 PDF는 상세 설정의 파일 URL 액세스도 켜 주세요.
